# 本番前の配線検査（dry-run）

## このページにあるもの

- 配線検査スクリプト: [`src/dryrun_wiring.py`](../src/dryrun_wiring.py)
- シグナル側の例: [`src/signal_ma_cross.py`](../src/signal_ma_cross.py)

## 要点だけ再掲

単体テストは「部品が仕様どおりか」を見ます。**部品同士がつながっているかは見ません。**
落ちたのは部品ではなく、部品の間でした。

検査するのは、関数の中身ではなく境界です。

- シグナルが本当に発注側へ渡っているか
- 銘柄名・時間足・ロット単位が、渡した側と受けた側で同じか
- 発注が拒否されたとき、戻り値を捨てていないか
- 時刻がローカル時間とサーバー時間で混ざっていないか

## 使い方

```bash
python src/dryrun_wiring.py
```

実弾を撃たずに、発注直前までの経路を1本ずつ通します。本番に上げる前に、これだけは毎回回します。

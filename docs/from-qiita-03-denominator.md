# 比べる前の分母チェックリスト

Qiita の記事「比べる前に、分母がそろっているか確かめる — 10日で3回踏んだ」から来た方へ。

## チェックリスト

2つの数字を並べる前に、上から順に確認します。

1. **割る前に足していないか。** 比の平均は「1件ずつ比を作ってから平均」。平均を作ってから割ると甘い方へ転びます
2. **経過時間がそろっているか。** 累計を並べない。1日あたり・1件あたりに直す
3. **ほかに違っている条件は無いか。** 1つの違いで説明する前に、公開日・媒体・経過日数・母集団を並べて書く
4. **転んだ向きを見る。** 欲しかった結論と同じ向きに出た数字は、検算の動機が湧きません。そこが危ない

## 実際に踏んだ3回

| やったこと | 出た結論 | 正しく直すと |
|---|---|---|
| 平均してから割った | コストは 0.0834 | 実効 0.1158（39〜46% の過小評価） |
| 経過日数が違う累計を並べた | 10.6倍の差がある | 日割りにすると差は消える |
| 条件が違うものを1つの違いで説明した | 投稿形式で 28→194 | 実測は 28→31 |

3つとも、**割る前に足した**か、**そろっていない分母のまま比べた**かのどちらかです。

# 小さな標本での合格判定は、どれだけ当たるか

Qiita の記事「『最初の30件でPF≥1なら合格』は、ほぼコイン投げだった」から来た方へ。

## 要点だけ再掲

実運用に上げる前の線を「最初の30件で PF ≥ 1.0 なら合格」と決めていました。始める前に止める線を引くのは正しいのですが、**その判定自体の当たり具合**を測ると、こうでした。

| | 30件で合格する確率 |
|---|---|
| 本物の優位（1件 +0.12R）がある場合 | 約6割 |
| 優位がまったく無い場合 | 約5割 |

**本物でも4割落ち、偽物でも半分が通ります。** 30件の PF 判定は、ほとんど情報を持っていません。

出し方は単純です。自分のバックテストの取引リストから1件あたりの分布を取り、

1. その分布から N 件を復元抽出して判定を通す → 本物を通す確率（検出力）
2. 同じ分布の平均を 0 にずらして同じことをする → 偽物を通す確率（偽陽性率）

を数千回ずつ回して数えるだけです。**N を決める前に、この2つを出しておく。**
